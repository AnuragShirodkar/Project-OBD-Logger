# Project GitHub workflow

These instructions apply to this entire project folder and its subfolders, across chats.

- The project's GitHub repository is https://github.com/AnuragShirodkar/Project-OBD-Logger.git.
- The user wants all relevant completed project changes, including code and documentation, committed and pushed to this repository as part of completing work in any chat. This is standing authorization; do not ask again for routine commits and pushes unless the user changes this instruction.
- If this folder is not yet a Git checkout, establish the repository connection before the first push, preserving existing local files and any remote history.
- Review changes and perform appropriate checks before committing. Include relevant project files; exclude secrets, credentials, local environment files, caches, and temporary build outputs.
- Preserve unrelated or unfinished work. Do not overwrite remote history or force-push without explicit authorization.
- Report the commit and push outcome accurately. If authentication or network access blocks a push, retain the local work and explain what is needed; do not claim it was uploaded.
- From now on, split work into small, meaningful commits and push each completed commit individually before proceeding to the next. Do not bundle independent changes into one large commit or accumulate multiple commits for one batch push. Keep tightly coupled changes together when needed for a coherent, working commit; do not create empty or artificial changes just to inflate the commit count. This applies across future chats and does not require rewriting existing history.
